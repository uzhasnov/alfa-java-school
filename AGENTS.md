# AGENTS.md

Проект `alfa-java-school` — учебный проект, предназначенный для выполнения домашних заданий в рамках курса Java + AT + Vibecoding.

Стек: Java 25, Gradle 9.6.1, JUnit 5 (Jupiter), RestAssured 5.5.7, Jackson 2.19.2 (сериализация DTO), Hamcrest (матчеры).

Пишем тесты только на Java 25. Если потребуется написать на другой версии, запроси разрешение.
